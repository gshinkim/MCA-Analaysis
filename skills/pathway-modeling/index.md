# Pathway Modeling — Wiki Index

Complete, verbatim conversion of the LaTeX source of Herbert M. Sauro, *Systems Biology: An Introduction to Pathway Modeling*, First Python Edition v1.22 (Ambrosius Publishing, ISBN 978-0-9824773-7-3).

One `.md` per source `.tex` file. **Nothing was removed.** Prose, equations, TikZ and pgfplots figure sources, tabular data, code listings, LaTeX comments and index terms are all preserved; `\ref` cross-references became wiki links.
